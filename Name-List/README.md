# Dự án Mini: Quản lý Danh sách Cá nhân (Name-List) 📇

Dự án nhỏ viết bằng Python phục vụ việc nhập, lưu trữ và quản lý thông tin cá nhân qua giao diện dòng lệnh (CLI).

## 🌟 Tính năng chính
1. **Nhập thông tin cơ bản:**
   - Họ và tên
   - Tuổi
   - Ngày tháng năm sinh (định dạng `DD/MM/YYYY`)
2. **Tính năng sáng tạo mở rộng:**
   - ⭐ **Tự động tính Cung hoàng đạo** dựa theo ngày/tháng sinh.
   - 🏡 Ghi nhận Quê quán / Nơi ở.
   - 🎨 Ghi nhận Sở thích cá nhân và Mục tiêu / Châm ngôn sống.
   - 💾 **Lưu trữ dữ liệu vĩnh viễn** vào file `danh_sach.json` chuẩn UTF-8 (dữ liệu không bị mất sau khi tắt chương trình).
   - 📋 **Trình bày thẻ ASCII Art** đẹp mắt cho từng hồ sơ.
   - 🔍 **Tìm kiếm nhanh** hồ sơ theo từ khóa tên.
   - 📊 **Thống kê phân tích:** Tổng số người, độ tuổi trung bình, người lớn tuổi nhất và nhỏ tuổi nhất.
   - 🗑️ Xóa hồ sơ không cần thiết.

## 🚀 Cách chạy chương trình
Mở Terminal tại thư mục này và chạy:
```powershell
python name_list.py
```
